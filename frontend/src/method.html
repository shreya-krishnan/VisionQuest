CH. 05 / METHODOLOGY two paths, one image

Behind every pixel, a process.

Explore the techniques behind our vessel maps. Both approaches process the same input image, with preprocessing specific to each approach.

From there the paths split. Classical processing enhances thin, elongated structures with hand-designed filters and turns the response into a binary map. U-Net learns those structures from annotated examples and predicts a vessel probability for every pixel.

Workflow Five stages · one input image
  1. 01

    Acquire

    A colour fundus photograph is uploaded.

  2. 02

    Preprocess

    Green-channel extraction and contrast enhancement.

  3. 03

    Segment

    Two independent paths.

    • ClassicalFilters + threshold
    • U-NetLearned per-pixel map
  4. 04

    Compare

    Outputs are viewed side by side and as overlays.

  5. 05

    Evaluate

    The fixed DRIVE validation subset is scored against its matching annotations.

Principle
A vessel map you can’t inspect is a vessel map you can’t trust.
